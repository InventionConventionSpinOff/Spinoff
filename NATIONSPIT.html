How It Works

The science and technology behind Spin Off

Step 1: Kick Detection

The IMU streams data via hardware FIFO at 1600 Hz. A kick is confirmed when raw accel exceeds 5 G for 3+ consecutive frames AND the gyroscope exceeds 150 °/s — eliminating false triggers when the device is still.

Step 2: Data Collection

During the 160 ms detection window, the firmware captures peak G-force, integrates velocity for speed, and simultaneously records 70 ms of microphone audio for strike analysis.

Step 3: Signal Processing

A Mahony orientation filter (fusing accelerometer + gyroscope + magnetometer) tracks orientation. Post-kick gyro samples estimate spin RPM, then blended with magnetometer rotation for a fused RPM value.

Step 4: AMIR On-Device ML

The AMIR system runs k-Nearest Neighbours classification against 7 kick archetypes, Welford online statistics for running averages, and least-squares trend analysis — all in under 1 ms with no external libraries.

Step 5: BLE Transmission

A flat JSON packet (≈512 bytes) is chunked into 160-byte BLE notifications and sent to the web app. The app reassembles chunks using newline termination, then displays all metrics instantly.

How the App Works

The web app receives flat JSON from the Arduino over Bluetooth. It parses fields like spd, rpmF, sq, and recs directly — no translation layer needed. Sessions are saved in browser localStorage, and you can export CSV or JSON reports at any time.

Frequently Asked Questions

Q: How do I save my session?
The app saves sessions locally when you start a new session or export data. View saved history on the Live Tracker page.

Q: What does spin axis mean?
The device classifies rotation as topspin, backspin, sidespin_left, sidespin_right, or mixed based on which gyroscope axis dominates during the post-kick settling window.

Q: What is "fused" RPM?
Fused RPM blends 70% gyroscope reading with 30% magnetometer-derived rotation, giving a more accurate ball spin value than gyro alone.

Q: Which browser works best?
Chrome, Edge and Opera support Web Bluetooth and give the most reliable connection. Firefox and Safari do not support Web Bluetooth.

Physics Behind the Metrics

Speed: Velocity is integrated from gravity-subtracted linear acceleration using the Mahony-estimated gravity vector, then frozen when the ball leaves the foot.

Spin Rate (Fused): Post-kick gyro magnitude averaged over 60 ms → converted to RPM, then blended with magnetometer-derived angular displacement.

Launch Angle: Derived from the frozen velocity vector's elevation above the horizontal plane.

Strike Quality: FFT of microphone audio during 70 ms contact window; scores zero-crossing rate, RMS energy, spectral sharpness, and contact duration.

Sensor Technology

BMI270: 6-axis IMU — ±16 G accelerometer at 1600 Hz + ±2000 °/s gyroscope at 3200 Hz, hardware FIFO buffering.

BMM150: 3-axis magnetometer for spin fusion and orientation heading.

LPS22HB: Barometric pressure sensor for altitude and air-density correction.

HS3003: Temperature and humidity sensor for environmental logging.

PDM Microphone: 16 kHz mono audio for strike quality via 256-point FFT.

Technology Stack

Built with cutting-edge hardware and software

Hardware

Microcontroller: Arduino Nano 33 BLE Sense Rev2
Processor: Nordic nRF52840 (64 MHz ARM Cortex-M4F)
IMU: BMI270 6-axis accelerometer + gyroscope

Wireless: Bluetooth 5.0 Low Energy

Software

Firmware: C++ (Arduino framework, mbed core)
Web App: HTML5, CSS3, JavaScript (ES6+)
Charts: Chart.js for real-time data visualization
AMIR AI: On device AI Built by the Spin Off team,
Connectivity: Web Bluetooth API — chunked BLE notifications
Browser Support: Chrome, Edge, Opera (Desktop & Mobile)

Our Mission

We created Spin Off because professional-level sports analytics shouldn't be limited to elite athletes with expensive equipment. Every player deserves data-driven insights to improve technique, track progress, and reach their goals. By combining affordable hardware with powerful AI, we're making sports analytics accessible to players of all levels.

The Journey

October 2025: Initial concept — "What if we could track soccer ball data?"

November 2025: Research phase — chose Arduino Nano 33 BLE Sense Rev2

December 2025: Prototype 1 — basic FIFO-based IMU readings and BLE streaming.

January 2026: Final version — AMIR on-device ML, added to AMIR dataset strike FFT, web app, and AI coaching complete.
